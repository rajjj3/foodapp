
# FoodApp - Online Food Ordering System

## About
FoodApp is a Java-based web application for online food ordering.
This project is currently under development.

## Technologies Used
- Java
- Jakarta Servlets
- JSP
- JDBC
- MySQL
- Apache Maven
- Apache Tomcat 10.1

## Architecture
The application follows the DAO design pattern, separating
model classes, DAO interfaces, DAO implementations,
controllers, and utility classes.

## Project Status
In progress. Features and documentation will be updated
as development continues.
